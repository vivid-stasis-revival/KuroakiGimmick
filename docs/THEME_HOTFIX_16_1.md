# v0.1.2 / 16.1 theme hotfix

## Fixed

The layout resize grips no longer render above the editor track-help card. While the help card is visible or fading, the grips are also excluded from pointer hit testing, so dragging cannot start through the document card.

## Themes

Open **SETTINGS → UI theme**:

- **Nekomiya** — current 16.1 blue/graphite palette. This is the default.
- **Scarlet** — legacy red/near-black palette from the earlier editor UI.
- **Kuroaki** — red/black palette with brighter text, stronger separators and lifted surfaces for higher contrast.

The theme is stored in the device settings only. It does not alter VSM/VSP/chart data, scene rendering, Note colors or video exports.
