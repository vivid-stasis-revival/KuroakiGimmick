# 历史资料边界

当前使用、构建和脚本入口统一见 [项目 README](../../README.md)。

`releases/` 归档了整理前的主 README、构建与打包说明、CHANGELOG、各次 HOTFIX / UPGRADE、修订说明与原始哈希清单。这些文件保留历史内容，其中命令、相对路径、素材分发描述和验证状态可能已经失效；请勿据此重复安装旧补丁或运行修复脚本。历史哈希仅描述整理前对应版本，不描述当前文件树。

`input-sdl-gpu/` 保存本次输入 ZIP 的原始 README、构建说明、版本说明与原始文件哈希清单；原文件没有被替换成 r19 验证结果。

`docs/validation/` 中除 `r19/` 之外的目录，以及 `docs/` 根目录既有的 `.log`、报告 JSON 和带历史提示的 Markdown，均随输入包已有。即便其中出现 PASS、133 项 CPU 测试、23 项 GPU 测试或逐像素一致，也仅属于它们原先记录的版本，不代表这次重构已经运行过。

r19 当次实际执行记录只写入 `docs/validation/r19/`，状态汇总在 `docs/VALIDATION_R19.md`。新增测试代码本身不是测试通过证据。
