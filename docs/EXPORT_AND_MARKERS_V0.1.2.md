# KuroakiGimmick v0.1.2 / 16.0

## 添加 gimmick

Editor 左侧的 `+ ADD GIMMICK` 打开参数窗口。Name 可输入尚未出现在时间轴中的原始 VSM 名称，无需先建立空轨道。填写 Beat、Duration、From、To、Easing 和 Proxy 后，选择 `ADD TO CHART`。

新增事件会创建对应的参数轨道、选中片段并滚动到它的位置。一次添加对应一次撤销。`_` 保留动态值语义；编辑框接受分数，写出时转为数值。新增名字支持中文图像／字幕标识，但不能包含逗号、换行或未填写的模板方括号。

`Proxy = -1` 是全局；其他值必须是当前已有 Proxy。文档作用域只用于建议初始值，不会自动改 `!obj`、`!proxies` 或注册新的渲染能力。未知名字可以写入，兼容报告仍然保留。

## E 插入标记

在 Editor 时间轴上把鼠标移到目标时间，按一次 `E`，按当前吸附规则记录拍点。鼠标不在时间区域时，E 标记当前播放游标。工具栏 `MARK / E` 始终标记游标。

标记显示在独立的 `MARKERS / E` 行。可创建多个标记；相同拍点不重复创建。当前活动标记使用金色竖线和 M 编号。选中音符或移动播放游标不会移动已固定的标记。

- 点击菱形：激活该标记并跳转到它。
- `Shift+E` / `UNPIN`：取消固定，保留书签。
- 右键菱形：删除该标记。
- 撤销和重做同时支持新增、切换、取消固定与删除。

普通添加、文档添加、轨道 `+`、窗口事件与复制片段的默认添加时间为：活动标记 > 选中音符 > 播放游标。双击轨道指定时间、或在添加窗口里手工填写 Beat，则使用显式时间。

这些是插入位置书签，不是新的曲线插值系统。标记保存到 `.sgv.json`，不生成 VSM 语句，也不修改 Note、VSV 或音乐。

## 文档右键添加

F1 中可在左侧参数条目、参数表行或参数页标题上右键。菜单提供 `添加` 和 `设置参数后添加`，并显示添加拍点。

具体参数名可以直接添加。`imgx_[图像名]`、`notealpind[lane]`、`textX_[tid]` 等模板会先打开参数窗口，要求填写实际名字。需要 Custom 对象但当前对象不匹配时，也先显示参数窗口及当前对象，不会自动换库。

添加后返回 Editor，选中刚添加的片段。原文档内容、字体、轨道悬停与 W 详情不变。

## EXPORT

Viewer 和 Editor 顶部均有 `EXPORT`。Editor 的 `Ctrl/Cmd+E` 也打开它；Viewer 原有 `Ctrl/Cmd+E` 视频导出保持原操作。

| 模式 | 输出 |
| --- | --- |
| VSM | 一个标准 `.vsm` 文件，包含当前尚未保存的编辑 |
| VSM + cgmk config | 同名 `.vsm` 与 `<名字>_cgmk_config.json`，包含当前窗口事件及原有配置字段 |
| Chart Folder | 新的歌曲目录，保留源目录文件，在新目录中写入当前难度的 VSM 和配置 |

选择模式与目标，点击 `REVIEW FILES`。检查文件列表和 notices 后，点击 `EXPORT COPY`。浏览文件或目录选择器会自动进入检查。导出不会把工程标为已保存；普通 `SAVE / SAVE AS` 仍用于保存编辑工程。

所有目标必须不存在。VSM 默认沿用实际谱面的难度文件名；手工改输出名时，放回游戏前仍需与谱面名匹配。Chart Folder 选择的是父目录，窗口中显示实际创建的新子目录。禁止导出到源歌曲内部，禁止覆盖源文件或已有目标。

### Chart Folder 的范围

复制原歌曲目录，包括其他难度、曲绘、音频、字幕、VSV、VSP 和未知普通资源；排除 Finder、Git、构建缓存、编辑工程副本及备份。只将当前难度替换为本次编辑内容，原目录不变。

已附加的 VSP 可导入输出目录。当前 VSP 引用的外部图片复制到 `_kuroaki_resources/images/`，并只改对应路径字段，保留其余字段、注释、BOM 和换行。附加的外部音频与曲绘也会复制；生成 `Kuroaki-export.sgv.json`，使用相对路径便于预览器重新打开。

文件夹导出的依赖整理以当前难度为范围；其他难度按原文件复制，不重写其独立外部引用。显式外部 FX/GameUI/Gimmick 素材包可能包含未知依赖，当前要求先把这些包放进歌曲目录再导出，不会只复制一个 manifest 就声称完整。符号链接、缺失依赖、跨平台冲突文件名会阻止导出并报告路径。未识别的配置字段原样保留，不能据此保证其私有外部依赖已收齐。

外部音频的复制不负责转码或自动改成游戏专用音乐名。文件夹中的预览工程可以定位它；游戏端仍需自己的音频命名及 ExtCustomGimmick 等扩展环境。`Chart Folder` 不是安装器，不包含主程序或 DLL/dylib 部署。

### 写盘保护

导出先冻结当前 VSM 和配置，在同一目标盘的私有临时目录中准备文件。检查源资源在预检后是否发生长度或修改时间变化，写入前再次检查目标冲突。

Chart Folder 使用新目录重命名提交。VSM/config 文件对使用暂存、非覆盖移动及异常回滚；这不是跨文件原子事务。进程被强制结束时，可能保留 `.kuroaki-export-*` 中的恢复日志。导出运行时可取消，关闭主窗口时先请求取消。

## 构建与验证

macOS：`bash scripts/publish-mac.sh`。Windows：`./scripts/publish-windows.ps1`。新包名称和应用版本为 v0.1.2 / 16.0。保留 .app / .exe 旁的 Assets。

实际生产 C# 自测入口：

```sh
bash scripts/verify.sh
```

Windows：`./scripts/verify.ps1`。它们先构建，成功后执行 `--authoring-self-test` 与 `--reference-self-test`；不会在构建失败时启动旧产物。

本次制作环境没有 .NET SDK，未执行 C# 编译、C# 自测或原生 UI。已执行的源代码结构、资源、文档和模拟发布检查见 `docs/validation-authoring.json`。模拟发布用假 dotnet 仅验证真实发布脚本的打包和失败处理，不是成功编译证明。
