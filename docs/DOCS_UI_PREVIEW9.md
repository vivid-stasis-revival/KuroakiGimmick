# v0.1.1 editor-preview.9：文档阅读界面与 UI 过渡

## 更新方式

本次基于 `KuroakiGimmick-v0.1.1-editor-preview.8-source.zip` 的 vsm-reference 版本。热修包在工程根目录覆盖，完整包建议解压到新目录；退出旧程序后重新构建并运行新发布目录里的应用。

```bash
cd ~/KuroakiGimmick-v0.1.1
unzip -o ~/Downloads/KuroakiGimmick-v0.1.1-preview.8-to-preview.9-docs-motion-hotfix.zip
./scripts/publish-mac.sh
```

Windows 继续使用 `scripts/publish-windows.ps1`。不需要 Python、MkDocs 服务或浏览器依赖才能运行文档界面；JSON 已生成并嵌入程序。

## F1 文档

界面保持在现有 SDL_GPU 应用内，采用章节导航、正文和本页目录的三栏布局。窄窗口的本页目录改为按钮打开的浮层。

- 左侧按 VSM 与 Custom Gimmick 分组，展开章节后查看参数和语法条目。点击表格中的参数行可进入对应说明。
- 中间分别绘制标题、正文、列表、参数表、提示和代码块，不再以整篇 Markdown、行号文本或两种重复模式呈现。
- 右侧目录跳转到本页小节，并跟随阅读位置高亮。代码块独立复制；不再提供复制整篇原始文档的按钮。
- 搜索支持原始名字、中文作用和多个关键词。`Ctrl/Cmd+F` 或 `/` 进入搜索；`Alt+Left/Right` 浏览历史；页脚可翻到上一页、下一页或返回章节。
- `F1` 或 `Esc` 关闭。从轨道悬停或选中片段打开 F1 时仍然定位相应参数。文档打开及关闭过渡期间不会把点击、滚轮或编辑快捷键传到下面的工作区。

说明卡和手册去掉自动附加的编辑器说明、原文标签、匹配提示标签及原文全文页。保留 205 条参数表项、10 项配置、29 个 obj、12 个 mpf、25 个语法入口和 20 个章节，共 301 个可浏览条目。原来 8 个辅助说明/原文全文入口不再进入导航或搜索结果。

`[lane]`、`[tid]`、`[图像名]`、`[0,1]` 等实际语法和范围保持不变。来源中的默认值、拼写、前提、单位和不一致之处没有被更改为新的执行规则。原始附件仍作为内部来源保留在 `Assets/Documentation`，不是 F1 的全文显示内容。

## UI 动画

统一的 UI 时钟负责过渡，不使用歌曲时间或每帧累加的进度。默认时长约 120–190ms，重复操作从当前显示状态开始过渡，不排队播放旧动画。

覆盖公共按钮的悬停、按下、选中反馈；Viewer/Editor 切换时的新界面淡入；Settings、帮助、值编辑、未保存确认和 F1 的打开/关闭；属性面板与文档内容切换；提示卡淡入淡出及展开高度；文档、轨道列表和属性面板滚动；时间轴片段选中状态、循环范围高亮和状态提示。

`Viewer UI → SETTINGS → UI transitions` 可以关闭过渡。该设置随应用偏好保存，不写入谱面工程或 VSM。

直接操纵仍然即时：播放游标、选中 note 的时刻、横向拍点定位、片段拖动、吸附和音量拖动不加缓动。歌曲求值、Note/特效渲染、窗口编舞和视频导出也不使用 UI 过渡。系统文件选择器由操作系统提供，不重绘或强制添加应用内动画。

命令行单帧 UI 截图自动关闭 UI 动画，以免只截到尚未显现的首帧；不会修改保存的偏好。

## 字体与保留内容

沿用 preview.8 的同一套比例黑体图集、字体度量和高对比正文。没有生成或替换任何字体资源，Viewer 原始字体、轨道原始名字、游戏 HUD 和游戏素材都不变。

窗口移动配置及原生桥接、VSM/VSP/VSV 解析、编辑文档和保存逻辑没有改动。Canvas 仅新增显式 UI 透明度作用域，默认值为 1，场景预览使用不受 UI 淡入影响的绘制作用域。

## 验证边界

当前交付环境没有 .NET SDK，尝试获取 SDK 时遇到 DNS 解析失败。没有完成 C# 编译、C# CPU 自测、SDL_GPU 运行或 macOS/Windows 原生交互验证。源码结构检查和离线布局示意均不等于编译或实机通过。

已执行的检查见 `VALIDATION_V0.1.1.md`。`--reference-self-test` 增加了动画时钟、反向切换、关闭动画、缓存清理、代码缩进、表格布局与页内锚点的 CPU 测试代码；其实际执行需要本地构建后进行。
