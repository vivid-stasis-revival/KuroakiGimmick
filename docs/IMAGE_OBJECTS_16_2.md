# KuroakiGimmick v0.1.2 / 16.2

## 更新

基于 16.1 clean source，并合入 Nekomiya/Scarlet/Kuroaki 主题、编译修复、说明卡 hover 与固定绘制层级的四个热修。增量包会一并补齐这些源文件，无需依次重装旧热修。它不包含任何系统字体文件，也不改动已有字体图集。

先退出旧程序、备份自己的源码改动，在已有的 16.1 工程根目录覆盖更新包，然后执行：

```bash
bash scripts/publish-mac.sh
```

Windows 使用 `scripts/publish-windows.ps1`。产物和应用标识为 v0.1.2 / 16.2；文件夹仍叫 v0.1.1 不影响实际版本。16.0 混合分支应先修复为 16.1，或直接使用本次完整源码包在新目录构建。不要把旧分支源码额外复制到完整源码内。

## 图片对象

Editor 左侧有 TOOLS / IMAGES。IMAGES 显示当前 VSP 的所有已加载图片实例，包含以前导入的图片和原本手写的 VSP 声明，不依赖导入日志。单击缩略图或对象轨道选择图片。

时间轴默认将某图片的 img* 参数收为一条对象轨。点击左侧展开按钮可查看原始参数轨道。打开分组不会改写文件；未解析或无法合并的图像事件仍在 RAW 片段或原事件列表中。

右侧 IMAGE / EVENT 切换对象面板和原事件面板。同一份 VSP/VSM 是编辑内容来源，没有额外隐藏的姿态数据。HIDE、LOCK、SOLO、画布缩放和中心只影响编辑视图，不是游戏可见性事件。

## 初始摆放与画布

选择图片后打开 IMAGE CANVAS。它是明确标注的 320×180 本地图片画布，显示网格和 VSP 图层，不把轨道代理、游戏 HUD、房间特效或屏幕扭曲混进坐标反算。SCENE 保留真实游戏预览；改完可随时切回验证演出。操作手柄、网格、路径和选中轮廓不会进入游戏文件和视频导出。

- INITIAL：修改图片最早的基础姿态。拖动内部移动；四角默认等比例缩放；边中点单轴缩放；顶部手柄旋转。
- LOCK RATIO 切换比例锁定；缩放时 Shift 临时反转比例锁定，旋转时 Shift 吸附到 15 度。
- 鼠标在画布内时，方向键移动 1 个游戏坐标单位，Shift 为 10；Ctrl/Cmd + 滚轮缩放查看。FRAME VIEW 定位选中图片，RESET VIEW 回到标准画布。
- 屏幕缩放/Retina 坐标先经现有 UI 换算，再经同一画布投影反算，不把物理像素直接写成图片坐标。
- 初始化值与同拍开始的普通动画相接时，INITIAL 会一并更新该动画起点，避免被旧起点覆盖。拖动期间只显示临时姿态，松手一次提交，Esc/窗口失焦取消；一整个拖动是一条撤销。拖动期间不允许保存、换图或其他编辑。
- 暂停时 0% 透明度的选中图显示编辑幽灵，实际 VSM 透明度不变。隐藏的图可从列表 SHOW，重叠图用 Alt+点击循环选择。

拖到预览图片区域时，新增图的初始中心使用鼠标落点的本地坐标；非图片区域或文件选择入口仍居中。导入后选中整个图片，不再只选一条 imgalp。当前对象库不支持 Custom 图片时仍要求显式确认切换，未自动换库。

## 定时姿态与动画

KEY HERE 使用活动 E 标记或当前播放游标对应的时间；移动/缩放/旋转时仅写入被修改的属性组。RECORD POSE 将六个基础属性记录成同一时刻的姿态。E 本身仍只是创作时间书签。

右侧顶部先选择 MOVE / SCALE / ROTATE / FADE IN / FADE OUT / POP IN，再按 + ANIMATION。默认从当前添加位置开始、持续 4 拍，选择新片段后可修改 Start、End、Easing。

1. 将图片摆好，在需要的时间标记 E。
2. 选 MOVE，再按 + ANIMATION。
3. 按 START 编辑起点，按 END 编辑终点；在画布拖动或在右侧输入 X/Y。
4. LOOP MOTION 循环试听该片段；CONTINUE 从该片段结束处添加下一段。
5. PATH LINES 显示运动节点，Alt+点击节点选择并修改端点。每段仍使用目标格式支持的缓动；不是任意贝塞尔曲线。

位置 X/Y 和成对的缩放 X/Y 是一个编辑动作；原始事件仍可展开。移动时间轴片段时整组平移，右边缘调整整组结束时间；DUP MOTION、DELETE MOTION 和撤销也按组处理。改变 BPM 的区间按当前求值器的起始 BPM 时长语义换算端点，不用结束拍减起始拍冒充真实结束时刻。

LINK JOINTS 默认打开：只把唯一、数值相接的相邻段一并更新。原本故意不连续的跳变不会被自动连接；关闭开关则独立调整所选段。PATH 模式偏移该图片全部数值 X/Y 事件，适合把完整路线挪到别处。

INITIAL、KEY HERE、START、END、PATH 的写入目标分开显示。游标停在别的时间时，开始画布编辑会先定位到明确的编辑目标，需要再次拖动，不在错误的时刻悄悄插帧。播放时实时显示动画，暂停后再编辑。

## 已有事件的保护

X/Y 使用不同时间或缓动、重复事件、动态值 `_`/573613、同一属性多条同拍写入，不能被假装成一组普通关键帧。它们保留原始事件视图。基础图片仍能被选择和查阅，但冲突编辑会拒绝并说明原因。

层内 imgxtime/imgytime/imgscaleytime 和非零/动态 skew 可能改变真实位置。为避免错误反算，相关直接变换受限，使用原始事件面板。此版本没有自由贝塞尔、任意透视扭曲反算、自动记录所有属性、多对象同时变换、把任意旧动画自动转为新曲线，也不修改图片自身的像素内容。

## 替换、保存、导出

REPLACE IMAGE 替换当前实例引用的资源，不改其它引用同一素材的实例，保留图片 ID、图层、原逻辑尺寸和已有动画。已有 animated 条带保留帧数，替换图片宽度必须能被帧数整除。

Save/Save As 沿用现有新工程副本规则：输出 .sgv.json、.editor.vsm、.editor.vsp、配置和 editor-assets；编辑姿态及动画写进 VSM，图片声明写进 VSP。替换的私有资源也进入保存和 Chart Folder 链路，原歌曲文件和原图片不覆盖。

VSM 或 VSM + cgmk config 两种导出仍不包含 VSP/图片；需要完整资源使用 Chart Folder。游戏端仍需对应 Custom Gimmick / ExtCustomGimmick。手柄只用于编辑，不等于给游戏新增可执行语法。

打开 `Samples/ImageObjects162/demo.sgv.json` 进入 Editor。它包含两个简单测试图案、现成 XY 路线、旋转、缩放和一个保留 `_` 的 RAW 透明度事件。

```bash
bash scripts/verify.sh

```
