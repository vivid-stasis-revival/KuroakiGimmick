# 中英双语界面

在预览界面顶栏打开 **SETTINGS / 设置**，或在编辑器左侧 **TOOLS / 工具 → SETTINGS / LANGUAGE / 设置 / 语言** 中选择语言：

- **跟随系统 / SYSTEM**：中文系统使用简体中文，其他语言使用英文。
- **中文**：固定为简体中文（`zh-CN`）。
- **English**：固定为英文（`en`）。

切换立即生效，无需重新打开工程。选择保存在用户 `settings.json` 的 `uiLanguage` 中，不写入 `.sgv.json`。旧设置缺少该字段、字段为空或语言不受支持时，回退到跟随系统。“恢复默认”也恢复跟随系统。

可以用 `--language zh-CN`、`--language en` 或 `--language auto` 指定本次界面的初始语言。该选项本身不写偏好文件；随后在界面保存设置时会保存当前选择。

## 范围

已本地化预览与编辑工作区、设置、布局、图片与文字面板、时间轴工具、右键菜单、导出流程、快捷帮助、内置轨道帮助，以及 UI 自身的状态和校验提示。

原始 VSM / JSON 标识符、文件路径、工程名称、歌曲元数据、用户输入与字幕保持原样。F1 离线参考文档的导航操作支持双语，附件导入的文档正文及其摘要保留原文，界面注明这一点。解析器、第三方工具及外部资源产生的技术诊断、命令行帮助和机器可读报告保持原有语言与格式。

语言切换不设置 `CurrentCulture` / `CurrentUICulture`，不触发谱面解析、播放重置或编辑撤销记录；拍数、小数与导出数据仍使用不依赖地区的格式。

## 翻译维护

`src/UI/Localization/en.json` 与 `zh-CN.json` 内嵌到程序集，独立于私有 `Assets/`。以原始 UI 文本为键，两份目录保持相同键集合。原来是中文的 UI 文案也有对应英文翻译。

在显示文案的源位置调用 `L.Get("PLAY")`。带变量时使用 `L.Format($"Added {name} at beat {beat:0.######}.")`，资源键对应 `Added {0} at beat {1:0.######}.`。翻译可重排参数，但必须保留参数索引与数值格式。不要先把变量拼成字符串再查表，也不要在通用文字绘制函数中自动翻译所有文本，以免误改用户内容。

缺失翻译时先回退英文，再回退原文。数组中的操作标识保持不变，在显示时查表；不要把翻译用于事件类型、文件格式或业务逻辑比较。

## 字体

主界面字体随当前界面语言切换：**中文使用 IBM Plex Sans SC Medium（标题也使用 Medium）**；**English 使用原来的 sans / mono / CJK 字体**，不替换英文字体或数字字体。“跟随系统”按最终解析的语言选择字体，启动和热切换保持一致。文档专用字体保留原有排版。

`Resources/Fonts/ui-sans*` 是从 SIL OFL 1.1 授权的 **IBM Plex Sans SC Medium / SemiBold** 生成的位图与度量数据，只覆盖语言目录需要的字符。它们随程序集内嵌，即使本地私有 Assets 中的旧图集没有新增汉字，也能正确显示中英文控件。字体源文件不进入仓库；生成的位图字体以 **Kuroaki UI Sans** 为名，独立保留 OFL 许可和来源声明，见 `ThirdParty/IBM-Plex-OFL.txt`。

新增文案后用本地 IBM Plex 字体重新生成（需要 Pillow 和 fontTools）：

```bash
python3 scripts/dev/build-ui-font-atlas.py \
  --regular /path/IBMPlexSansSC-Medium.woff \
  --bold /path/IBMPlexSansSC-SemiBold.woff
```

支持 TTF、OTF 和 WOFF；WOFF2 另需 Brotli 解码依赖。普通编译和运行不需要 Python、系统字体或联网。新增语言时应同步扩展 `UiLanguage`、`L` 的资源加载、选择器及字符覆盖测试。

## 验证

`--self-test` 检查双语键集合、占位符、全部界面字符的字体覆盖、热切换、语言回退、偏好保存、旧设置迁移和地区无关的数值格式。

```bash
dotnet build -c Release
dotnet run -c Release --no-build -- --self-test
dotnet run -c Release --no-build -- --smoke-i18n --language zh-CN --out /tmp/i18n.ppm
dotnet run -c Release --no-build -- /path/project.sgv.json --editor --smoke-i18n --out /tmp/i18n-editor.ppm
dotnet run -c Release --no-build -- --snapshot --settings --language en --out /tmp/settings-en.ppm
```

`--smoke-i18n` 需要图形设备，在 1180×860 和 1440×940 下渲染两种语言，检查切换不会更换 Session、修改工程/演出内容或移动播放头，不保存测试语言偏好。
